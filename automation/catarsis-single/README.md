# Single-channel Catarsis generation

Adds a distinct `generation_start_single` operation to the existing local broker.
The existing pair operation and its validation continue to generate both channels.
Each new single request stores one selected channel and one topic; the worker
calls the existing supervised build exactly once. A Facts-only job does not test,
authorize or acquire Revelations' Epidemic music. Complete account history is still
read for deduplication, and the native source, readiness, pause, budget, metadata,
licensing, technical QA and visual-review checks remain active.

The current request is one English, text-led, 50–59 second vertical Catarsis Short
for Stunning Facts of History about Marie Curie's WWI mobile radiography work.
Native metadata includes YouTube, Facebook and Instagram captions and all credits.
This release generates only; it never publishes or requests TikTok drafts.

Use the stable request file with `single_catarsis_request.py --start`. Repeating it
returns the existing batch. It does not reset budgets or retry a blocked job.
Progress and signed previews are available through the existing
`catarsis_generation_status(batch_id)` connector operation. The unselected channel
is explicitly `not_requested` for compatibility with older preview clients.
`pair_sha256` remains empty for a single job, so it cannot be submitted to the pair
publication tool by accident. The documentary broker also blocks a single start
while a documentary is active, preserving mutual exclusion.

vidIQ found topical Curie Shorts, including History Diaries' `jsEIDI5ZHuM`
(about 17,800 views; 9.4x its channel baseline at the time of research). This supports
interest in Curie, not a measured forecast for the mobile-radiography angle. The
broader YouTube search returned mostly unrelated examples and was excluded.
No external clips, scripts, visual identities or soundtrack are copied from those
examples. The native editor must fetch and verify factual evidence and licenses.

Repository and VPS documentation/code are persisted with the release. Earlier v47
consolidation is installed first if its receipt is absent. Original historical jobs,
approvals, source receipts, publication IDs and daily timer settings are preserved.
