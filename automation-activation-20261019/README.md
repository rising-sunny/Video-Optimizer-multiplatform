# Paquete de activación para la IA local

Este paquete contiene instrucciones, política confirmada y ejemplos de unidades. No contiene credenciales, código de agente terminado ni prueba de activación del VPS.

Leer ACTIVAR_AUTOMATIZACION_VPS.md y el informe de credenciales ya existente en el VPS. La IA local tiene acceso SSH; debe implementar el controlador real y el agente, probarlos y activar los timers desde ese acceso, conforme a la autorización del usuario. Los archivos .example necesitan adaptación al controlador real; no instalarlos a ciegas.

La nube verificó únicamente la sintaxis de las cuatro expresiones OnCalendar con systemd-analyze calendar. La validación completa de unidades, proceso como videoagent y flujo editorial corresponde al VPS. No afirmar que está activo hasta verificarlo allí.

Horarios confirmados: primer día 20-10-2026, preparación 12:00, History 19:00 y Revelations 19:30 America/Santiago. El 26-10 solo el short de Revelations a las 20:30. B-59 no se modifica. Fin del calendario inicial 14-11-2026, sin repetición automática ni recuperación de atrasos.
